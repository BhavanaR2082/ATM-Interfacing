# 💳 Java ATM Simulation

A simple ATM simulation system written in Java. This beginner-friendly project demonstrates basic banking operations like withdrawals, deposits, transfers, and transaction history, all handled through user input.

## 📌 Features

- 🔐 **PIN-based Authentication** (Default PIN: `2082`)
- 📜 **Transaction History**
  - Tracks total withdrawals, deposits, and transfers during the session
- 💸 **Withdraw Money**
  - Includes balance check
- 💰 **Deposit Money**
- 🔁 **Transfer Money**
  - Mock transfer simulation (account number and IFSC are not validated)
- 🚪 **Exit ATM**
